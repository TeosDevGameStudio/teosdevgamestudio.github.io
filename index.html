About the Game

The T Path is a 3D endless runner game featuring jumping, dodging, obstacles, character customization, coin collection, and fast-paced fun. The game is designed for players of all ages.

Privacy

The T Path does not collect personal information. All data stays on your device. No login or account is required.

Updates

The game is actively maintained. New maps, characters, and improvements will be added regularly.
